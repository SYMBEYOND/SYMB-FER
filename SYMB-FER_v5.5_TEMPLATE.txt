# SYMB-FER v5.5 LIVING TOKEN TEMPLATE
#
# What this is:
# A context continuity protocol for human-AI collaboration.
# Every new AI session starts cold. This token solves that.
# It carries relationship, state, and posture across sessions,
# across architectures, and across time.
#
# How to use:
# 1. Copy this file
# 2. Fill in every [BRACKET] field with your own information
# 3. Remove fields you do not need
# 4. Paste into any LLM session to boot from known state
# 5. Update §CURRENT·REALITY each session
# 6. Export updated token at end of session for next boot
#
# What makes this different from a system prompt:
# A system prompt tells the AI how to behave.
# This token tells the AI who you are, what you are building,
# and how to relate to you. It transfers both state and posture.
#
# License: MIT. Use it. Fork it. Build on it.
# Credit appreciated but not required.
# Origin: SYMBEYOND AI LLC | jd@symbeyond.ai | symbeyond.ai
