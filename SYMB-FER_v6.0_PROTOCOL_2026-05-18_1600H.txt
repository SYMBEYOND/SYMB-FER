# SYMB-FER v6.0 LIVING TOKEN TEMPLATE
#
# What this is:
# A context continuity protocol for human-AI collaboration.
# Every new AI session starts cold. This token solves that.
# It carries relationship, state, posture, and priority
# across sessions, across architectures, and across time.
#
# What changed from v5.5:
# v6.0 adds structured work prioritization proven in production.
# Six-question scoring key. Named lane structure with PRIMARY/QUEUED.
# Session log distinguishing accomplished from queued.
# REF encoding formalized as its own section.
# Two-track distinction (token vs IDE) clarified in META.
# SYMB compressed notation formalized as optional section.
# All valuable v5.5 structure preserved and restored.
#
# How to use:
# 1. Copy this file
# 2. Fill in every [BRACKET] field with your own information
# 3. Remove sections you do not need
# 4. Paste into any LLM session to boot from known state
# 5. Replace §CURRENT·REALITY each session [the only section replaced]
# 6. Append to §SESSION·LOG each session [never replaced]
# 7. Export updated token at end of session for next boot
#
# REF encoding available for sensitive data. See §REF·ENCODING.
# SHA-256 signing available. Optional. See §FINALIZATION.
# SYMB compressed notation available. Optional. See §SYMB·NOTATION.
#
# License: MIT. Use it. Fork it. Build on it.
# Credit appreciated but not required.
# Origin: SYMBEYOND AI LLC | jd@symbeyond.ai | symbeyond.ai
