## SYMB-FER orientation

SYMB-FER is a user-controlled context-continuity protocol for carrying structured state and relational posture across otherwise stateless AI sessions. The token is the primary traveling artifact; the Runtime IDE is a separate tool that serves the token.

The repository currently documents two separately versioned tracks: Token Track v6.2 and Runtime IDE Track v4.0. The CHANGELOG identifies v6.2 as the current token release and notes that it adds interpretation guardrails and a time anchor.

Important distinctions and boundaries:

- Do not conflate the Token Track with the Runtime IDE Track; they version independently.
- A token provides supplied context to a receiving model. It does not create persistent memory unless the host system actually provides persistent memory.
- Token content is operator-provided context, not independent proof of legal, medical, financial, personal, historical, or scientific claims.
- Filled living tokens may contain sensitive personal, relationship, business, or client context. Do not expose, commit, or infer such material during ReBoot maintenance.
