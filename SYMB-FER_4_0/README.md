## What This Is

The SYMB-FER Runtime is a browser-based tool that brings the SYMB-FER protocol to life.

No install. No dependencies. Open the HTML file in any browser and it runs.

---

## What It Does

- **Load** — paste any SYMB-FER token and the Runtime parses it instantly, reconstructing session state, boot facts, ethos, and working context into a live panel
- **Work** — use the built-in command interface to store state, display output, and build a traceable action log
- **Export** — generate a valid SYMB-FER v4.0 token from the current session, ready to paste into your next chat

Every session leaves a door open for the next one. That is the point.

---

## How To Use It

1. Open `symb_runtime_v4_0.html` in any browser
2. Press **LOAD EXAMPLE** to see a token parsed immediately
3. Or paste your own token and press **LOAD TOKEN**
4. Work in the Runtime using the command input
5. Press **EXPORT TOKEN** when done
6. Copy the exported token and paste it into your next AI session

---

## Commands

| Command | What it does |
|---|---|
| `display [text]` | Render text to output |
| `state [key] [value]` | Store a key/value pair |
| `show state` | Dump the KV store |
| `trace` | Show full action trace |
| `replay` | Replay all actions from trace |
| `undo` | Remove last action and replay |
| `clear` | Clear output panel |
